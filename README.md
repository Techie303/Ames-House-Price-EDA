# Ames House Price EDA website

This folder is a static site. Open `index.html` locally to preview it. It includes the dashboard image, the runnable notebook, and its companion CSV.

## Publish with GitHub Pages

1. Create a GitHub repository for this project and upload all files in this folder to the repository root.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. GitHub will show the public site URL in the Pages settings after publishing completes.

The page and its downloadable notebook and CSV will be publicly accessible to anyone with the link. The data is a public Ames housing training dataset.
